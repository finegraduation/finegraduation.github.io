# Assets Directory

## Video Background

### Required Video File:
- **Filename:** `graduation-bg.mp4`
- **Recommended specifications:**
  - Resolution: 1920x1080 (Full HD) or higher
  - Format: MP4 (H.264 codec)
  - Duration: 10-30 seconds (will loop)
  - File size: Under 10MB for web optimization
  - Content: Graduation ceremony, academic environment, or elegant abstract visuals

### Video Sources:
You can obtain suitable videos from:
1. **Free Stock Video Sites:**
   - Pexels Videos (pexels.com/videos)
   - Pixabay Videos (pixabay.com/videos)
   - Unsplash Videos (unsplash.com)

2. **Recommended Search Terms:**
   - "graduation ceremony"
   - "university campus"
   - "academic achievement"
   - "elegant abstract"
   - "minimalist background"

### Fallback Image:
- **Filename:** `graduation-fallback.jpg`
- **Purpose:** Displays when video is loading or not supported
- **Recommended specifications:**
   - Resolution: 1920x1080
   - Format: JPEG
   - File size: Under 500KB
   - Content: Similar theme to video

## Installation Instructions:

1. Download a suitable video file
2. Rename it to `graduation-bg.mp4`
3. Place it in this `assets/` directory
4. Optionally, add `graduation-fallback.jpg` for fallback support
